# Crypto-CI: The Trust Manufacturing Pipeline

**The software industry has spent two decades optimizing for velocity. We have built pipelines that can deploy code to millions of users in seconds. We have automated everything: testing, integration, delivery, and operations.**

**And yet, the trust foundation of every one of these systems is quietly collapsing.**

## We Believe:
1. **The pipeline is the root of trust.**
2. **Harvest Now, Decrypt Later is not a future threat.**
3. **Inventories are the foundation of defense.**
4. **Security must be a property of the system.**
5. **Regression is the enemy.**
6. **Trust must be verifiable, not assumed.**
7. **The shift from velocity to assurance is inevitable.**

## The Toolchain
This repository contains the "Golden Pipeline" — a GitHub Action that implements Level 3 Crypto-CI. It automatically generates a CycloneDX Cryptographic Bill of Materials (CBOM) and fails builds if quantum-vulnerable primitives are introduced.
